publicum.txt is the same data converted to a compact format for Gayathri MediRecord:
line 1 holds the list of remedies; each following line is one rubric:
parent rubric number <TAB> rubric text <TAB> remedies (2 base-36 characters for the remedy, 1 digit for the grade).
